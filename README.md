# مشغّل الصوت + ملاحظات

## الرفع على GitHub Pages
1. أنشئ مستودع جديد على GitHub (يفضّل Private إذا حسابك يدعم Pages للخاص، أو Public).
2. ارفع الملفات: `index.html` و `config.js` (و README اختياري).
3. من المستودع: Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://اسمك.github.io/اسم-المستودع/`

## تغيير اليوزر وكلمة السر
افتح `config.js` وغيّر قيمة `AUTH_HASH` (الشرح داخل الملف).
الافتراضي: `admin` / `1234`.

## تنبيه أمني
GitHub Pages مواقع ثابتة بدون سيرفر، فالتحقق يصير داخل المتصفح. هذا يمنع الدخول العادي، لكنه ليس حماية حقيقية
(أي شخص متمكن يقدر يقرأ الكود). لا تحط ملاحظات سرية جداً. اختر كلمة سر طويلة.
